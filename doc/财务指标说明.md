# 财务指标说明

在财务分析中，不同的指标有不同的使用方式，有些只需要查看最新一期的数据，而有些需要连续观察它们的变化趋势，以更全面地评估公司的财务状况。

## 1. 最后一期数据即可查看的指标

这些指标通常反映当前状态或最直接的财务表现，单一数据就足够帮助判断公司的当前状况。

### 常用指标 (CM)

| 指标名称 | 代码 | 说明 |
|---------|------|------|
| 常用指标_归母净利润 | CM_NPAS | 通常每个季度或年度的归母净利润即可反映公司的盈利状况 |
| 常用指标_营业总收入 | CM_TOR | 反映公司营业收入的总体规模，查看最新数据即可 |
| 常用指标_净利润 | CM_NP | 净利润是最常用的盈利能力指标，只需查看最近一期数据 |
| 常用指标_基本每股收益 | CM_BEPS | 每股基本收益，主要反映公司每股的盈利情况，查看最新一期 |
| 常用指标_毛利率 | CM_GM | 反映公司产品或服务的盈利能力，单一数据通常就可以反映当前状态 |
| 常用指标_净资产收益率(ROE) | CM_ROE | 反映股东回报率，查看最新一期数据即可 |
| 常用指标_资产负债率 | CM_ALR | 反映公司财务杠杆，查看最新一期即可 |

### 每股指标 (PSI)

| 指标名称 | 代码 | 说明 |
|---------|------|------|
| 每股指标_基本每股收益 | PSI_BEPS | 每股基本收益，只需查看最后一期数据 |
| 每股指标_每股现金流量净额 | PSI_NCFPS | 衡量公司每股现金流情况，查看最新一期 |

### 财务风险 (FR)

| 指标名称 | 代码 | 说明 |
|---------|------|------|
| 财务风险_流动比率 | FR_CR | 短期偿债能力指标，查看最后一期即可 |
| 财务风险_速动比率 | FR_QR | 速动比率也反映短期偿债能力，查看最新一期 |
| 财务风险_现金比率 | FR_CashR | 直接衡量现金流的短期偿债能力，只需查看最新一期数据 |

### 收益质量 (EQL)

| 指标名称 | 代码 | 说明 |
|---------|------|------|
| 收益质量_经营活动净现金/销售收入 | EQL_NOCF_SR | 反映现金收入占销售收入的比重，查看最后一期即可 |

## 2. 需要滚动查看的指标

这些指标更侧重于长期的趋势分析，观察一段时间内的变化，帮助评估公司经营或财务状况的长期健康。

### 常用指标 (CM)

| 指标名称 | 代码 | 说明 |
|---------|------|------|
| 常用指标_扣非净利润 | CM_NRNP | 去除非经常性损益后的净利润，需要查看多个周期的数据来判断公司核心盈利的稳定性 |
| 常用指标_股东权益合计(净资产) | CM_TSE_NA | 股东权益的变化需要滚动查看，反映公司长期财务健康 |
| 常用指标_经营现金流量净额 | CM_NOCF | 经营现金流量的长期趋势非常重要，滚动查看多个周期的数据 |
| 常用指标_每股净资产 | CM_NAPS | 查看多个周期数据，帮助了解公司每股净资产的增长趋势 |
| 常用指标_总资产报酬率(ROA) | CM_ROA | 这是公司资产使用效率的关键指标，需要连续查看 |
| 常用指标_销售净利率 | CM_NPM | 需要查看多个周期来分析盈利能力的变化 |
| 常用指标_期间费用率 | CM_PER | 费用与收入的比率，需要长期观察其变化 |

### 盈利能力 (PCP)

| 指标名称 | 代码 | 说明 |
|---------|------|------|
| 盈利能力_净资产收益率(ROE) | PCP_ROE | 需要观察多个财报周期的数据，看是否稳定增长 |
| 盈利能力_总资产报酬率 | PCP_ROA | 需要查看多个财报周期的数据，了解公司资产的使用效率 |
| 盈利能力_毛利率 | PCP_GM | 长期观察毛利率的变化趋势，帮助分析公司的盈利质量 |
| 盈利能力_销售净利率 | PCP_NPM | 长期观察销售净利率，反映公司经营管理能力 |

### 成长能力 (GCP)

| 指标名称 | 代码 | 说明 |
|---------|------|------|
| 成长能力_归母净利润增长率 | GCP_GRNPAPC | 增长率指标需要连续查看，帮助判断公司是否有持续增长的潜力 |
| 成长能力_营业总收入增长率 | GCP_TORGR | 营业收入增长的变化趋势需要滚动观察，反映公司是否在扩大市场规模 |

### 营运能力 (OCP)

| 指标名称 | 代码 | 说明 |
|---------|------|------|
| 营运能力_应收账款周转率 | OCP_ART | 需要观察多个周期的数据，分析公司的资金流动效率 |
| 营运能力_应收账款周转天数 | OCP_ARTD | 需要连续查看，帮助判断公司资金周转速度 |
| 营运能力_存货周转率 | OCP_IT | 分析存货管理的效率，通常需要长期观察 |
| 营运能力_存货周转天数 | OCP_ITD | 分析存货管理效率的变化，需要查看多个周期的数据 |

## 总结

* **最后一期即可查看**的指标：如净利润、每股收益、毛利率、资产负债率等。
* **需要滚动查看**的指标：如扣非净利润、总资产报酬率、ROE、营运能力指标等。

这些指标反映公司的财务健康和成长性，连续观察可以帮助判断公司的长期发展趋势和经营状况。
